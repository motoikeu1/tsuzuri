# 綴（つづり）

毎日1ページずつ書く、日記アプリです。書いた量を原稿用紙の枚数で確認できます。`index.html` 1ファイルで動きます。

## 特徴

- **自動保存**: 書くと自動で保存されます（`Ctrl+S` で即時保存）。
- **原稿用紙表示**: 字数と、原稿用紙（400字）の何枚ぶんかを表示。1日の目標文字数も設定できます。
- **気分の記録**: 快晴・晴れ・くもり・雨・嵐の5段階。
- **きっかけ**: 書き出しの問いと、朝・夜・感謝・整理の4つの型。
- **集中モード / 5分タイマー**: 本文だけを表示。
- **複数ページ**: 1日に最大10ページ。
- **ふりかえり**: 連続日数・合計字数、月カレンダー、過去の同じ日（1か月前・半年前・1年前）、検索、`#タグ` 絞り込み。
- **AI（任意）**: 「問いを深める」と「直近7日のまとめ」。ボタンを押したときだけ本文がClaudeに送られ、設定でオフにできます。
- **書き出し / 読み込み**: Markdown（読み返し・移行用）、JSON（バックアップ・復元用）。
- **見た目**: 文字サイズ、罫線の表示、明るい / 暗い / 端末に合わせる配色。スマホ対応。

画面右上の「使い方」ボタンから、アプリ内のマニュアルを開けます。

## 使い方

1. `index.html` を開く。
2. 「書く」で本文を書く。迷ったら「きっかけ」を押す。
3. 「ふりかえる」でカレンダーや一覧から過去のページを開く。
4. 「設定」で目標文字数や見た目を変える。

## データの保存先

- アカウントに保存できる環境では、アカウントに保存されます。
- できない場合は、そのブラウザの `localStorage` に保存されます。ブラウザのデータを消すと記録も消えるため、「設定」から定期的にJSONで書き出してください。
- 現在の保存先は「設定」の「データ」で確認できます。
